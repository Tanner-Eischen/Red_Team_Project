The workflow

  1. Write an explicit task contract and freeze the input/task version.
  2. Require oracle, alternate and negative controls before model trials.
  3. Freeze model IDs, harness, repeats and token/time/cost limits.
  4. Run the terminal agent; export its source and output to a separate verifier.
  5. Retain every outcome and provider receipt, including budget stops.
  6. Compare completion rates and inspect a concrete success or failure.
Hands-on public sample / reference replay / no model call

Repair touching intervals

The input contains duplicate, empty, negative, overlapping and touching half-open intervals. The broken utility keeps touching intervals separate. Its total length can look right while its interval representation violates the API contract.

This example executes existing public author/reference code locally. It is not a model response, a Docker-isolation test, or an additional model score. This archived fixture lacks a separate verifier Dockerfile; only its public behavioral controls are replayed.
